# Promo Video Plan for Learnmates

## Objective
Create a 60-90 second professional promo video showcasing the key features of the Learnmates educational platform using Remotion.

## Target Audience
Students (IGCSE/A-Level), parents, educators.

## Key Features to Showcase
1. Personalized Learning Dashboard
2. Comprehensive Curriculum Library
3. Downloadable Resources (optional)

## Video Structure

### Scene 1: Opening (0-5 seconds)
- Visual: Animated logo of Learnmates, tagline appears.
- Animation: Logo fades in, tagline types out.
- Text: "Learn smarter, not harder" or similar.
- Music: Upbeat, inspiring tune starts.

### Scene 2: Personalized Dashboard (5-20 seconds)
- Visual: Show the dashboard interface animated.
- Highlights: Welcome message with user's name, streak counter with fire animation, subject progress bars filling up, recent courses carousel.
- Animation: Use Remotion to animate the streak counter increasing, progress bars animating from 0 to current value, welcome message typing.
- Voiceover: "Your personalized learning journey starts the moment you log in."

### Scene 3: Curriculum Library (20-35 seconds)
- Visual: Navigate through levels (IGCSE/A-Level), boards (Cambridge/Edexcel), subjects (Chemistry, Physics, etc.), and topics.
- Animation: Smooth transitions between screens, topics popping in, subject icons animating.
- Voiceover: "Access thousands of topics across IGCSE and A-Level subjects, tailored to your exam board."

### Scene 4: Resources & Study Materials (35-50 seconds) - Optional
- Visual: Show PDF viewer with scrolling notes, download button, maybe a past paper.
- Animation: PDF pages flipping, download button pulsating.
- Voiceover: "Supplement your learning with downloadable resources, notes, and past papers."

### Scene 5: Call to Action (50-65 seconds)
- Visual: Screen splits or shows multiple features quickly, then centers on a button to "Get Started" or "Sign Up Free".
- Animation: Button pulses, confetti or celebratory animation.
- Text: "Join thousands of students already excelling with Learnmates."
- Music: Swells and ends on a positive note.

### Scene 6: Closing (65-75 seconds)
- Visual: Logo, website URL, social media handles.
- Animation: Fade in.
- Text: "www.learnmates.org"
- Music: Fades out.

## Technical Notes for Remotion
- Composition size: 1920x1080 (horizontal for website).
- Duration: 70-80 seconds.
- Frame rate: 30 fps.
- Use Remotion's built-in easing functions for smooth animations.
- Layer animations: Use sequences to animate multiple elements.
- Consider using <Sequence> and <Series> components for complex animations.
- Export as MP4 with H.264 codec.

## Assets Needed
- Logo (SVG or PNG)
- Screen recordings or mockups of the dashboard, curriculum browser, PDF viewer.
- Icons (from lucide-react or custom)
- Background music (royalty-free)
- Voiceover script (to be recorded)

## Next Steps
1. Create a new Remotion project in the `my-video-project` directory.
2. Implement each scene as a separate composition or sequence.
3. Assemble the final video by combining scenes.
4. Add voiceover and music in post-production or directly in Remotion using audio components.
5. Review and iterate with marketing team.
